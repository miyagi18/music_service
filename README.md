# Тема проекта: Сервис поиска музыкальных коллективов

## Назначение: Удобный поиск музыкальных групп, артистов, лейблов и их музыкальной дискографии

## Целевая аудитория: 
- **Все люди, которые любят слушать музыку** ;

## Описание предметной области: 
- Музыкальная индустрия и цифровые каталоги. Область охватывает данные о создателях музыки (артистах и группах), их треках и компаниях, занимающихся их продюсированием и распространением песен(лейблах). 



## Основные сущности: 
- **Артист (Artist):** Имя артиста (или дуэта), жанр, список релизов*, лейбл (если артист состоит в нем)
- **Песня (Song):** Название песни, жанр, год выпуска, текст (если есть) 
- **Лейбл (Label):** Название, список артистов*, год основания, страна
- (На будущее (Связи между сущностями): У одного артиста может быть много песен, но у песни только один артист; У лейбла может быть много артистов, но у артиста лейбл только один)
## Основные функции: 
1. **Управление сущностями (CRUD):** Добавление, просмотр, редактирование и удаление информации об артистах, песнях и лейблах.
2. **Поиск и фильтрация:** Поиск артиста или песни по названию; фильтрация треков по жанру или году выпуска.
3. **Просмотр дискографии:** Получение списка всех песен, принадлежащих конкретному артисту или выпущенных на конкретном лейбле.

## План развития проекта: 
По ходу развития проекта планируется:
- Переход на ООП (создание сущностей и взаимосвязи между ними)
- Разработка веб приложения на Django
- Подключение к бд (Postgres) с использованием ORM
- Разработка REST API
- Написание тестов
