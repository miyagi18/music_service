# Music Service — сервис поиска музыкальных коллективов

## Назначение

Music Service — веб-приложение для поиска музыкальных коллективов,
их песен и лейблов. Изначально проект был консольным (ПР1–ПР3),
в ПР5 получил веб-интерфейс на Django.

Приложение позволяет:

* просматривать список лейблов и их артистов;
* просматривать список артистов и их дискографию;
* просматривать каталог песен;
* просматривать заявки пользователей на поиск коллектива;
* переходить по связанным сущностям (артист → лейбл, песня → артист
  и т. п.);
* открывать карточки сущностей по динамическим URL;
* получать собственную страницу 404 при несуществующем URL или объекте.

## Используемые технологии

* Python 3;
* Django 5.2 — веб-фреймворк;
* HTML — разметка страниц;
* CSS — оформление (тёмная тема в стиле Spotify);
* pytest — автоматизированные тесты;
* flake8 — проверка качества кода.

## Целевая аудитория

Люди, интересующиеся музыкой: слушатели, исследователи музыкальной
индустрии, пользователи, ищущие коллективы по названию, жанру или стране.

## Предметная область

Основные сущности:

* **Лейбл (Label)** — музыкальная компания, выпускающая артистов;
* **Артист (Artist)** — группа, дуэт или сольный исполнитель;
* **Песня (Song)** — музыкальная композиция конкретного артиста;
* **Пользователь (User)** — пользователь сервиса;
* **Заявка (Request)** — заявка пользователя на поиск коллектива
  с указанием желаемого названия, жанра и страны.

Связи:

* у артиста один лейбл (связь «многие-к-одному»);
* у песни один артист;
* заявка связывает пользователя и (при обработке) найденного артиста.

## Основные классы предметной области

Классы живут в пакете `models/` и представляют предметную область ПР3.

| Класс | Назначение | Ключевые атрибуты |
|-------|-----------|-------------------|
| `Label` | Музыкальный лейбл | `id`, `name`, `founded_year`, `country` |
| `Artist` | Артист / группа | `id`, `name`, `country`, `label` |
| `Song` | Песня | `id`, `title`, `artist`, `genre`, `release_year`, `duration_sec`, `has_lyrics` |
| `User` | Пользователь сервиса | `id`, `name`, `email`, `city` |
| `Request` | Заявка на поиск коллектива | `id`, `user`, `query`, `genre`, `city`, `status`, `found_artist` |

Ключевые методы:

* `from_data()` — создание объекта из словаря JSON (`@classmethod`);
* `to_dict()` — сериализация объекта в словарь JSON;
* `__str__()` — строковое представление;
* `Request.is_active()`, `take_in_work()`, `complete()`, `cancel()` —
  жизненный цикл статуса заявки.

## Страницы веб-интерфейса

| URL | Назначение |
|-----|-----------|
| `/` | Главная страница |
| `/labels/` | Список лейблов |
| `/labels/<int:label_id>/` | Карточка лейбла и его артисты |
| `/artists/` | Список артистов |
| `/artists/<int:artist_id>/` | Карточка артиста и его дискография |
| `/songs/` | Список песен |
| `/songs/<int:song_id>/` | Карточка песни |
| `/requests/` | Список заявок |
| `/requests/<int:request_id>/` | Карточка заявки |

Если объект с указанным ID не найден или URL не соответствует ни одному
маршруту — отдаётся собственная страница 404 (`templates/404.html`).
